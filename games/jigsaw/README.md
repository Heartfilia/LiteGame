# 拼图

经典模式提供 12、24、48、96 块，以及大屏可用的 150 块，保留轮廓引导和固定位置吸附。

## 自由难度 · 20×20

选择顶部 **自由 · 20×20**，开始 400 块拼图。图片沿用原有 3:4 比例，分成 20 列、20 行。

- 工作区为纯色空白，不显示底图或网格。散块留在下方托盘，可拖入任意位置；也可先点选散块，再点击工作区放下。
- 只有图片中真正相邻、方向与位置吻合的拼块才会吸附。拼块和组合都不会锁定在工作区的固定位置。
- 合并后可抓住任意成员移动整个组合；两个组合可以继续合并。400 块连成一个整体时完成，完整拼图仍可拖动。
- 拖动空白处平移，滚轮或按钮缩放；“查看全部”将工作区中的所有组合纳入视图。托盘中的块不参与该视图计算。
- 选中组合后，方向键微调，Shift＋方向键大步移动，Enter 尝试吸附，Esc 取消当前拖动／选择。
- 自动保存托盘顺序、自由位置、组合关系和视图。刷新可继续，完成的自由拼图也保留；换图或切换难度会开启新局。

## 实现

- `index.html`：原有图案绘制、切块、经典模式，以及自由模式入口和存档接入。
- `free.js`：独立组合引擎。以拼块宽高为坐标单位，每组共享一个图片原点；根据真实四邻接关系合并，不以图形相似或固定槽位判断。存档校验包含去重、坐标、成员完整性与组内连通性。
- `free-board.js`：Canvas 工作区，命中检测使用拼块轮廓而非矩形；缓存 400 个拼块，只在交互时重绘。支持指针捕获、取消回滚、缩放坐标转换、视图移动与键盘微调。

验证命令和边界见 `tests/README.md`、`tests/AUDIT.md`。
