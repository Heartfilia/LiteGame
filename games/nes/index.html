玩法与存档

底部“开始”可直接启动模拟器，运行后变为“暂停”，暂停后变为“继续”；也可用 START / SELECT 启动或唤醒。等待卡带标题画面出现后，再按 START 进入游戏，SELECT 选择模式（具体作用由游戏决定）。唤醒时不同时发送游戏按键，避免误触游戏内暂停。方向键移动，Z = A、X = B、Enter = START、右 Shift = SELECT。双人游戏：玩家二用 I/J/K/L、G/H、T/Y。手机可同时按方向与 A/B，连发键适合射击。

“存档”保存当前画面进度，“读档”恢复当前卡带的存档。切到后台会暂停；回到页面需手动继续。存档保存在此浏览器中，清理网站数据会删除存档；大厅的进度导出不包含 FC 存档。

“横屏游玩”将方向键放在左侧、A/B 放在右侧，画面居中。支持的浏览器会全屏并锁定横屏；iPhone 等不支持时使用网页内横屏，可将手机横拿。左上角“菜单”可以存读档或退出横屏，退出后游戏暂停。
