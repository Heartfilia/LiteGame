# 雾灯镇：遗迹之钥

原创、无第三方游戏引擎的像素回合制 RPG。直接通过 HTTP 打开 `index.html?from=rpg`；沿用 LiteGame 的导航、主题与反馈音效。游戏独有的源码、地图、图形与封面总量以 `tests/fogtown.test.cjs` 的 1,000,000 字节上限验收；没有远程素材、音频下载或运行时依赖。

## 内容与操作

- 雾灯镇、萤火森林、回响矿洞、无光遗迹四张手工地图。
- 三枚钥印、三个首领、可完成的灯塔主线；采药与救援两条支线、三个一次性宝箱。
- 12 种敌人，预告攻击/蓄力/重击/护甲/吸魔意图。
- 普攻、打断重击、穿甲法术、防御回魔、两种消耗品、非首领撤退。
- 12 级成长上限，两种成长路线，武器/防具/饰品；吸血、反击、减魔耗效果。
- 免费旅店与恢复点；败退扣少量金币，保留人物与世界进度；可重置普通怪物继续训练。
- 键盘方向键/WASD，E/空格交互，B 背包，J 任务，数字 1—7 战斗。
- 手机方向按钮支持长按、释放/取消；相邻格可点选；对话和战斗均为大按钮。地图默认跟随放大，顶部网格按钮切换区域全图。横屏、窄屏与安全区域适配。

## 文件

- `index.html`：独立规则引擎及静态地图、物品、怪物数据，可在 Node VM 中测试。
- `game.js`：界面、像素绘图、输入、对话、生命周期。
- `style.css`：手机/桌面布局与弹窗。
- `save.js`：浏览器和 Node 共用的存档编码、验证与读写事务顺序。

## 永久进度

主键 `litegame.fogtown.save`，备份键 `litegame.fogtown.save.backup`。不调用小游戏的 `ctx.finish()`，通关不清存档，不重复领取公共结算奖励。

状态包含人物坐标、朝向、等级、经验、生命/魔力、成长路线、道具、装备、首领与普通敌人击败记录、一次性物品、任务标志、当前战斗回合、确定性随机数状态、手记与游戏时间。

每次状态操作保存；活动时间每 15 秒保存，失焦/隐藏/离开页面补存。先把上一份有效状态写入备份，再更新主存档；写入失败显示错误，不声称保存成功。存档包含格式版本、数据版本、校验码；读入时按白名单重建状态，验证数值、地图、物品与任务一致性。校验码用于损坏检测，不是防作弊机制。

- 主存档损坏：载入上一份有效备份。
- 两份均损坏：暂停自动覆盖，提供导入或明确重开。
- 检测到未来版本：保留原数据，提示使用对应版本。
- 多标签页：比较当前存储与本页读取值；收到真实外部更改时锁定旧页面。忽略刷新前旧文档产生、但值已被新文档读取的过期 storage 事件。
- 导出/导入：便携 JSON，文件限 250KB。确认导入后才写入，先备份当前有效状态；格式错误不改原存档。

初始格式为版本 1。当前不假造历史版本迁移；以后修改格式须先新增显式迁移函数和旧版本 fixture 测试，再提升版本号。浏览器清站点数据会删除本地进度；换设备/域名需手动导出导入，不提供账号云存档。

## 验证

```sh
node --test tests/fogtown.test.cjs
node tests/fogtown.browser.cjs
GAME_IDS=fogtown node tests/all-games.browser.cjs
```

浏览器命令依赖 Playwright 和本地静态服务器，详见 `tests/README.md`。`RPG_SHOTS` 可指定已存在的截图输出目录。
